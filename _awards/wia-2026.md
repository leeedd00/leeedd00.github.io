## 과제

공작기계 주축(스핀들) 양산 검사는 스핀들을 500~8000rpm으로 돌리며 3축 진동을 재고, 검사원의 관능평가(소리·촉감)와 주파수(FFT) 평가를 합쳐 OK/NG를 냅니다. 발주처 검사 기록에는 관능평가와 종합평가만 채워져 있고 **주파수평가와 AI평가 두 칸은 비어 있었습니다.** 이 두 칸을 진동 데이터만으로 채우는 것이 과제였습니다.

- 데이터: raw 파일 244개(KF5600 · KF5600C · KF6700 · KF6700II), NG 55. 파일마다 축 × RPM 블록 27~36개, 블록 하나는 6초 × 25,600Hz
- NG 55건 = 관능 D형 34건(사람이 잡음) + FFT형 21건(진동에서만 걸림)

## 접근

**파싱과 정합성 확인**: 헤더가 224/240바이트 두 형식으로 섞여 있어 자동 판별 파서를 만들고, 공식 변환 프로그램 출력과 전 블록 파형이 일치(최대 차 5e-7)하는지 검증했습니다. 관능 D인데 OK로 기록된 2건은 주최측에 확인해 라벨을 정정했습니다.

**특징 추출**: 블록마다 DC를 제거하고 결함 물리와 연결되는 지표 20개를 계산했습니다. 시간영역(RMS · 피크 · 첨도), 회전차수(1X · 2X · 3X), 대역 RMS와 ISO 10816 속도 RMS, 포락선, 베어링 제원으로 계산한 결함차수(BPFO 11.33X · BPFI 13.67X · BSF 5.05X · FTF 0.453X). 파일 하나는 축 3 × 지표 20 × RPM 요약 5 + 기종 = 303차원 벡터가 됩니다.

**탐색 분석**: 차이는 고속(6000~8000rpm)의 저주파 지표에서 가장 컸고 X축이 가장 민감했습니다. 단일 지표 AUC 약 0.85. 베어링 결함 주파수 진폭 단독은 AUC 약 0.7로 약했습니다.

## 모델

| 모델 (입력 동일: 진동 특징 303개) | ROC-AUC | 비고 |
|------|------|------|
| 단일 지표 기준선 | 0.841 | 임계값 하나 |
| 로지스틱 회귀 | 0.860 | 선형 |
| 랜덤포레스트 | 0.898 | 트리 600 |
| LightGBM | 0.887 | 얕은 트리 |
| **베이지안 로지스틱 (채택)** | **0.865** | 사후분포 갱신 · 확률 보정 |

(기종, 측정일) 그룹 5겹 교차검증 × 시드 3. 같은 날 측정된 파일은 한 그룹으로 묶어 수리 후 재측정이 학습·검증에 섞이지 않게 했습니다. 네 모델의 차이는 표본 오차(±0.04) 안이라 정확도로는 우열을 가릴 수 없었습니다.

**정확도가 같다면 기준은 과제가 요구하는 나머지 조건입니다.** 라벨이 쌓이면 갱신되어야 하고(베이지안은 사후분포를 다음 사전분포로 넘겨 옛 데이터를 다시 읽지 않아도 전체 학습과 같음), 재검사 판정에 불확실성 근거가 있어야 하며(학습 데이터가 적은 영역은 확률을 0.5 쪽으로 보수적으로), 판정 근거를 설명해야 합니다(상위 계수 = X축 속도 RMS · 1X · Z축 500~1kHz가 곧 사유). 세 조건을 만족하는 베이지안 로지스틱을 택했습니다.

**판정 체계**: 등급 A~D는 정상품 확률 분포의 50 · 95 · 99 백분위로 나눠 "정상 100대 중 N대보다 나쁨"으로 읽히게 했고, 판정은 불량 확률 p + 베어링 점수 z + 관능평가를 규칙으로 합쳐 OK / HD(재검사) / NG를 냅니다. 놓침 0을 지키는 가장 작은 재검사 구간(22%)을 경계로 채택했습니다.

## 결과

| 항목 | 값 |
|------|------|
| 진동만으로 낸 불량 확률 ROC-AUC | 0.865 |
| 규칙 결합 시 NG 놓침 · 재검사 비율 | 0건 · 22% |
| 사람이 못 잡은 FFT형 NG 검출 | 21 / 21 |
| 순차 갱신 실험 (24개 묶음 × 6회) | 오경보 55 → 36 |

raw 파일을 넣으면 파싱 → 특징 추출 → FFT 판단 → 판정 규칙 순으로 처리되어 판정 카드와 웹 화면이 나옵니다. 판정 카드에는 확률이 OK/HD/NG 구간 중 어디에 있는지, 지표 9종이 정상품 대비 어느 위치인지, 축 × RPM별로 어떤 지표가 「주의」 이상인지가 한 장에 담깁니다. "AI는 사람이 놓친 것을 잡고, 사람은 AI가 놓친 것을 잡는다"가 결론이었습니다.

## 배운 점

- **정확도가 같을 때 무엇으로 고를 것인가.** 갱신 가능성, 불확실성, 설명 가능성이라는 운영 조건이 모델 선택의 기준이 됐습니다. 이 사고방식은 Keeping에서 LLM 대신 수식으로 판단하도록 바꾼 결정과 같은 결입니다.
- **검증 설계가 결과를 좌우합니다.** 같은 날 측정 파일을 한 그룹으로 묶지 않으면 성능이 부풀려집니다. Purdue에서 카운티 그룹 교차검증을 쓴 것과 같은 이유였습니다.
- **비용 비대칭은 학습 가중치가 아니라 임계값에서.** NG 놓침이 오경보보다 비싸다는 사실을 재검사 구간으로 흡수하는 설계를 배웠습니다.
- **한계를 숨기지 않기.** 관능 D이면서 진동이 정상인 5건은 어떤 진동 모델도 못 잡는다는 것을 그대로 적었고, 그것이 "관능을 규칙에 넣는" 설계 근거가 됐습니다.
